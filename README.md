# Featured Data Analytics Project

## 🌍 Global CO2 Emissions Dashboard | Power BI

A data analytics project exploring global carbon emissions through data analysis and visualization using Power BI and Excel.

The project investigates trends in emissions across countries, emission sources, economic growth, and Brazil's contribution to global emissions. It also explores the relationship between cumulative emissions and global warming.

Key questions explored:

Which country emits the most today, and which has emitted the most throughout history?

How have global emissions evolved since 1990?

Which source (coal, oil, gas, or cement) has the largest impact worldwide?

Which countries managed to grow their GDP while reducing emissions (decoupling)?

What is Brazil's share of global emissions, how has it changed, and what is its main source today?

How do accumulated emissions relate to global warming?

Tools: Power BI | Excel

Besides practice and knowlegde, my goal also was to turn environmental data into clear visualizations that help explore historical patterns, compare countries, and understand the dynamics of global carbon emissions.
